# Hotel Network Project

## Overview

This project focuses on designing and configuring a hotel network using Cisco networking technologies.

The network is designed to connect different areas of the hotel while keeping the network organized and separated where needed. The project also includes routing, VLANs, IP addressing, and connectivity testing.

## Project Objectives

The main goals of this project are to:

* Design a hotel network topology
* Configure Cisco routers and switches
* Assign IP addresses to network devices
* Configure VLANs where required
* Configure routing between different networks
* Provide communication between different network segments
* Test and verify network connectivity
* Document the network configuration

## Network Components

The network is built using Cisco networking devices and end-user devices, including:

* Routers
* Layer 2 switches
* End-user PCs
* Servers and other network devices required for the topology

## Technologies Used

* Cisco Packet Tracer
* IPv4
* VLANs
* Inter-VLAN Routing
* Static/Dynamic Routing
* Switching
* Spanning Tree Protocol (STP)
* Network Troubleshooting

## Network Areas

The hotel network is divided into different network areas based on the requirements of the hotel.

Each area is configured to provide the required connectivity while keeping the network structured and manageable.

## Configuration

The complete device configurations are stored in:

```text
configurations/
```

This folder contains the configuration files for the routers and switches used in the project.

## Verification

After completing the configuration, network connectivity was tested using commands such as:

```text
ping
show ip interface brief
show vlan brief
show ip route
show running-config
```

These tests were used to make sure the devices, VLANs, interfaces, and routing were working correctly.

## Project Outcome

This project provided hands-on practice with designing and configuring a real-world style hotel network using Cisco Packet Tracer. It also helped strengthen practical skills in switching, routing, VLANs, IP addressing, and troubleshooting.
