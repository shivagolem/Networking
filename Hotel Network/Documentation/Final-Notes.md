# Final Notes

## Project Summary

The Hotel Network Project demonstrates the implementation of a multi-floor hotel network using Cisco networking technologies.

The project includes VLAN segmentation, DHCP, Router-on-a-Stick, OSPF dynamic routing, and SSH-based device management.

## Key Learning Outcomes

Through this project, the following networking concepts were practiced:

- IPv4 addressing
- Subnetting
- VLAN configuration
- Inter-VLAN routing
- DHCP configuration
- OSPF configuration
- Serial router connections
- Trunking
- Spanning Tree Protocol
- SSH
- Network verification

## Network Management

The network is organized by floor and department, making it easier to manage and troubleshoot.

OSPF provides dynamic route exchange between routers, while VLANs provide logical separation of departments.

## Future Improvements

Possible improvements include:

- Implementing ACLs for better security
- Adding redundancy
- Implementing centralized network monitoring
- Adding wireless access points
- Introducing network automation using Python
- Implementing additional security controls

## Final Conclusion

This project provides practical experience in designing, configuring, and troubleshooting a Cisco-based hotel network in Cisco Packet Tracer.
