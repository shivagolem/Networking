# Hotel Network Project - Overview

## Introduction

This project demonstrates the design and configuration of a hotel network using Cisco routers and switches.

The network is designed to provide connectivity between different floors and departments of the hotel while keeping the network organized and separated using VLANs.

## Network Design

The hotel network is divided into different floors and departments.

Each floor has its own router and multiple VLANs. Router-on-a-Stick is used to provide communication between VLANs on each router.

OSPF is used as the dynamic routing protocol to provide communication between the different routers.

## Main Technologies Used

- Cisco Routers
- Cisco Switches
- VLANs
- Router-on-a-Stick
- DHCP
- OSPF
- SSH
- IP Addressing
- Packet Tracer

## Project Objectives

- Design a hotel network topology
- Configure routers and switches
- Configure VLANs
- Configure DHCP
- Configure inter-VLAN routing
- Configure OSPF routing
- Provide communication between network segments
- Verify network connectivity
- Document the network configuration
