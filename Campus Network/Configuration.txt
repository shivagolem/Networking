CAMPUS NETWORK - CONFIGURATION NOTES
=====================================

This file contains the main configuration commands and IP details used in my Packet Tracer project.
Configure each block on the correct device. Do not paste all blocks into one device.

3. CORE-SW2
-----------
Configure the same VLANs as CORE-SW1.
Use this base configuration and the SVI values below.

enable
configure terminal
hostname CORE-SW2
ip routing
spanning-tree mode rapid-pvst
spanning-tree vlan 10,20,30,40,50,60,70 root secondary

interface fastethernet0/1
 no switchport
 ip address 10.0.2.2 255.255.255.0
 no shutdown
exit
ip route 0.0.0.0 0.0.0.0 10.0.2.1

Trunk ports Fa0/2-Fa0/6: allow VLANs 10,20,30,40,50,60,70.
EtherChannel Fa0/7-Fa0/8: channel-group 1 mode active.
Port-channel 1: trunk, allow VLANs 10,20,30,40,50,60,70.
Fa0/9: trunk, allow VLAN 50 only.

CORE-SW2 SVI addresses and HSRP:
VLAN 10: IP 10.10.10.3, HSRP virtual IP 10.10.10.1, priority 100
VLAN 20: IP 10.10.20.3, HSRP virtual IP 10.10.20.1, priority 100
VLAN 30: IP 10.10.30.3, HSRP virtual IP 10.10.30.1, priority 100
VLAN 40: IP 10.10.40.3, HSRP virtual IP 10.10.40.1, priority 100
VLAN 50: IP 10.10.50.3, HSRP virtual IP 10.10.50.1, priority 100
VLAN 60: IP 10.10.60.3, HSRP virtual IP 10.10.60.1, priority 100
VLAN 70: IP 10.10.70.3, HSRP virtual IP 10.10.70.1, priority 100

On each SVI, configure:
 standby <VLAN-ID> ip <virtual-gateway>
 standby <VLAN-ID> priority 100
 standby <VLAN-ID> preempt
For VLANs 10,20,30,40,60,70 also configure:
 ip helper-address 10.10.50.10
Do not add DHCP helper to VLAN 50.


4. R1
-----
enable
configure terminal
hostname R1

interface fastethernet0/0
 ip address 10.0.1.1 255.255.255.0
 ip nat inside
 no shutdown
exit
interface fastethernet0/1
 ip address 10.0.2.1 255.255.255.0
 ip nat inside
 no shutdown
exit
interface serial0/0/0
 ip address 10.0.3.1 255.255.255.0
 ip nat outside
 no shutdown
exit

ip route 10.10.0.0 255.255.0.0 10.0.1.2
ip route 10.10.0.0 255.255.0.0 10.0.2.2 10
ip route 0.0.0.0 0.0.0.0 10.0.3.2

access-list 1 permit 10.10.0.0 0.0.255.255
ip nat inside source list 1 interface serial0/0/0 overload
end
copy running-config startup-config

If the serial DCE side needs clocking, configure clock rate 64000 on the DCE interface only.


6. ACCESS SWITCHES
------------------
Create VLANs 10,20,30,40,50,60,70 and enable:
spanning-tree mode rapid-pvst

ACCESS-SW1 and ACCESS-SW2:
- Fa0/1-Fa0/2 are trunks. Allow VLANs 10,20,30,40,50,60,70.
- Fa0/3-Fa0/4 are access VLAN 30.
- Fa0/5 is access VLAN 20.
- Fa0/6 is access VLAN 20 with voice VLAN 70.
- Port security is enabled on endpoint ports; maximum 1, except phone port maximum 2; sticky MAC enabled.

ACCESS-SW3:
- Fa0/1-Fa0/2 trunks.
- Fa0/3-Fa0/5 access VLAN 30.
- Fa0/6 access VLAN 40.

ACCESS-SW4:
- Fa0/1 trunk.
- Fa0/2-Fa0/4 access VLAN 30.
- Fa0/5 access VLAN 40.

ACCESS-SW5:
- Fa0/1 trunk.
- Fa0/2-Fa0/3 access VLAN 30.
- Fa0/4 access VLAN 20.
- Fa0/5 access VLAN 60.

ACCESS-SW6:
- Fa0/1-Fa0/2 trunks.
- Fa0/3 access VLAN 60.
- Fa0/4 access VLAN 40.
- Fa0/5 access VLAN 60.

DHCP relay is configured on both core switches for VLANs 10,20,30,40,60,70 using:

9. ACCESS CONTROL LISTS
-----------------------
Student ACL (apply inbound on interface VLAN 30 on both core switches):
ip access-list extended STUDENT-RESTRICTION
 deny ip 10.10.30.0 0.0.0.255 10.10.10.0 0.0.0.255
 permit ip any any
exit
interface vlan 30
 ip access-group STUDENT-RESTRICTION in

Guest ACL (apply inbound on interface VLAN 40 on both core switches):
ip access-list extended GUEST-RESTRICTION
 permit udp any eq 68 any eq 67
 permit udp 10.10.40.0 0.0.0.255 host 10.10.50.10 eq 53
 permit tcp 10.10.40.0 0.0.0.255 host 10.10.50.10 eq 53
 deny ip 10.10.40.0 0.0.0.255 10.10.0.0 0.0.255.255
 permit ip any any
exit
interface vlan 40
 ip access-group GUEST-RESTRICTION in


10. SSH
-------
Configure on CORE-SW1, CORE-SW2, R1 and ROUTER-ISP.
Use your own lab password.

ip domain-name campus.local
username netadmin secret <YOUR-LAB-PASSWORD>
crypto key generate rsa
ip ssh version 2
line vty 0 4
 login local
 transport input ssh
exit


11. PORT SECURITY
-----------------
On the selected end-device access ports:
switchport mode access
switchport port-security
switchport port-security maximum 1
switchport port-security mac-address sticky

For the IP phone port on ACCESS-SW1 and ACCESS-SW2, use maximum 2 because the phone and a PC can share that port.


12. IMPORTANT VERIFICATION COMMANDS
-----------------------------------
show vlan brief
show interfaces trunk
show cdp neighbors
show spanning-tree summary
show spanning-tree vlan 30
show etherchannel summary
show standby brief
show ip interface brief
show ip route
show access-lists
show ip nat statistics
show ip nat translations
show port-security address

Tests:
- PC receives DHCP address from its VLAN range.
- PC can ping its HSRP gateway.
- DNS resolves www.campus.local to 10.10.50.20.
- Browser opens http://www.campus.local.
- FTP server is reachable at files.campus.local.
- Student VLAN cannot reach Management VLAN.
- Guest VLAN cannot reach internal networks except allowed DHCP/DNS.
- HSRP failover changes the active gateway when tested.
- NAT test reaches 203.0.113.1 and creates a translation.
