# Project 1 – Enterprise Network Configuration

##  Project Overview

This project demonstrates the design and configuration of a small enterprise network using Cisco networking concepts.

The network was configured with multiple switches and a router to provide connectivity between different network segments.

##  Objectives

* Design a basic enterprise network topology
* Configure routers and switches
* Configure IP addressing
* Configure VLANs
* Configure inter-VLAN communication where required
* Configure routing
* Verify connectivity between network devices
* Troubleshoot network connectivity issues
